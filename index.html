Paridade do Poder de Compra (PPP)

A PPP é a base teórica mais clássica de equilíbrio cambial. Ela assume que, no longo prazo, a taxa de câmbio deve se ajustar para que o poder de compra seja o mesmo em ambos os países. Cálculo: diferencial de inflação acumulada entre Brasil (IPCA) e EUA (CPI) a partir de uma base de equilíbrio. Sinal de "barato": se o dólar nominal estiver significativamente abaixo do PPP, o real está sobrevalorizado (dólar barato); se acima, o real está subvalorizado (dólar caro).

Diferencial de Juros Real (Carry Trade)

O câmbio é extremamente sensível à atratividade do capital. Este painel compara o juro real ex-ante brasileiro (Selic ajustada pelo Focus IPCA 12m) com o juro real ex-ante americano (Fed Funds ajustado pelo Michigan 1y inflation expectations) e cruza o spread BR−EUA com o câmbio R$/US$. Interpretação: se o spread sobe e o dólar não cai proporcionalmente, há divergência — o real está barato demais perante o prêmio oferecido (ou o dólar caro). Fórmula de Fisher: r = (1+i)/(1+π) − 1.
